# 🧠 BrainFit Application

A **mobile brain-training application** designed to enhance **analytical thinking** and **memory skills** through interactive exercises and games.

Built with **React Native**, BrainFit offers a seamless and cross-platform experience on both **iOS** and **Android**.  
The app utilizes **Google Sheets** as a lightweight backend for storing and managing user data — making it simple yet effective for tracking cognitive performance and progress over time.

---

## 🚀 Features
- Engaging brain-training mini games  
- Cognitive and memory improvement exercises  
- Data storage and tracking via Google Sheets  
- Cross-platform mobile support (iOS & Android)  
- Clean and user-friendly UI  

---

## 🛠️ Tech Stack
- **Framework:** React Native (Expo)
- **Database:** Google Sheets API
- **Language:** JavaScript / TypeScript
- **Platform:** Android & iOS
